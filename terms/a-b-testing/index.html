Experiments and measurement

A/B Testing

A/B testing compares two versions of an experience by randomly assigning eligible users to each one. It is useful when a team needs to know whether a change caused an improvement rather than just coinciding with one.

A checkout experiment, end to end

A hypothetical online store wants to remove an unnecessary address field. It assigns 10,000 eligible visitors to each version:

  • Original checkout: 400 purchases, a 4.0% purchase rate.
  • Short checkout: 440 purchases, a 4.4% purchase rate.

The observed lift is 0.4 percentage points, or 10% relative. That sounds encouraging. But the store should not declare success until it checks statistical uncertainty, revenue per visitor, refunds and whether assignment worked.

If the shorter checkout also offers a discount, the test no longer isolates the field removal. The next experiment should separate the interventions.

Set up the event and assignment correctly

Choose a stable visitor identifier, define eligibility, and keep users in the same variant on return visits. Track the purchase event on the confirmation server or another reliable source, not just clicks on “Buy.”

Before launch, write down:

  • Primary outcome: purchases per eligible visitor.
  • Guardrails: order value, refunds, support contacts.
  • Run length and estimated sample required for a meaningful effect.
  • How to check for sample ratio mismatch or broken tracking.

The count of clicks on the shortened form is a diagnostic, not the purchase outcome.

The result may be inconclusive

If the confidence interval includes both a small loss and a useful lift, the test did not settle the decision. That does not prove the two checkouts are equivalent. Run longer or accept uncertainty, depending on business stakes.

For repeated experiments, document each result in a shared log, including decisions that were reversed later. That prevents the team from retesting the same idea with no memory of what happened.

Growth experimentation covers the broader decision process, while incrementality testing applies similar causal reasoning to media campaigns.
